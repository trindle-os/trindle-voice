# Security

## Supported versions

| Version | Supported |
|---|---|
| Latest release | Yes |
| Older releases | No |

## Reporting a problem

Please report security problems privately first, using GitHub's private vulnerability
reporting on this repository (Security tab, "Report a vulnerability"). If that is not
available to you, email voice@trindle.org. Please do not open a public issue for a
security problem.

Trindle Voice is a small project run by a few people. We will read your report and reply
as soon as we can, and we will credit you in the changelog if you want that. We cannot
promise a fixed response time.

Upstream Supertonic is archived and receives no fixes, so problems in code inherited from
it are fixed here.

## Voice files

The model and voice files are downloaded by hand and are trusted input: they are parsed
as they are, with no size limit. Check them against `SHA256SUMS` before use.

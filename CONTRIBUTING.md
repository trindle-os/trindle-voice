# Contributing

Thank you for your interest in Trindle Voice.

Code changes are not taken at the moment. That is simply how the project is set up. What
helps most is a clear description of what you saw:

- what you did
- what you expected
- what happened instead
- the version and your setup (distribution, processor, which voice)

Report it through the Trindle community at https://trindle.buildmorphic.com with those details. Security problems go private: see [SECURITY.md](SECURITY.md).
